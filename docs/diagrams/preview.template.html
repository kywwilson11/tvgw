Every figure, redrawn

Every Mermaid diagram in the repository is gone. Where a picture teaches something the text cannot, it became one of these sixteen figures, each one idea with every wire labelled; where the diagram only redrew a numbered list or a table already on the page, the list or the table stayed and the diagram went. Each figure is plain HTML and CSS on one stylesheet of tokens: cool neutrals, one cobalt accent for the path the figure is about, quiet role tints, brick only for what is refused, labels at 15 to 16 px on an 8 px grid, and wires computed from named anchors. GitHub cannot run HTML in a README, so each page embeds the figure as light and dark PNGs at 2x inside a <picture> element, rendered from this same source.

Shown here live, not as images.
